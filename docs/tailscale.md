# Tailscale

The admin for access to my tailscale network is a bit tedious. I have to invite user to GH org -> they accept -> they login to tailnet -> I approve. Managing users thru GH org gives me some nice control over accounts tho.

Also I am forcing 2FA which I know some people don't like. I think it's worth it since I am exposing my home network to the public internet, so extra security is worth the trade off of tedium here. 

In my tailnet I have it configured for devices to stay logged on for 180 days (max value allowed) so theoretically users will only have to go thru the login flow with 2FA twice a year.
