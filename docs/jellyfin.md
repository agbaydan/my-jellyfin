# Jellyfin

I have been using jellyfin locally for a while now and have had no issues with it. My server running it at home should have more than enough power to handle many simultaneous streams. I suspect my internet bandwidth will be a bottleneck long before my hardware is. 

I have a GPU in my server so I enabled hardware acceleration: https://jellyfin.org/docs/general/post-install/transcoding/hardware-acceleration/
That should make my setup even more powerful for streaming.
